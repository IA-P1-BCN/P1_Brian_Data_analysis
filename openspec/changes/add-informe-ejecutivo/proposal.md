# Proposal

## Why

El análisis no sirve si no se comunica. Hoy no hay informe ejecutivo, el
README sigue siendo el enunciado original y no hay ningún gráfico
interactivo. Sin estos entregables, el nivel Medio y el Avanzado no se
pueden demostrar.

## What Changes

- Escribir `reports/informe.md` (1–2 páginas, audiencia CEO, en español).
- Actualizar `README.md` con origen de datos, instalación, ejecución y
  estructura.
- Añadir al menos un gráfico interactivo con Plotly.
- Enlazar cada hallazgo del informe con una celda o figura reproducible.

### New Capabilities

- `informe`: informe ejecutivo, README y visualización interactiva.

### Modified Capabilities

Ninguna.
